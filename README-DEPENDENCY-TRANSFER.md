# Install and run at home

This delta requires the installed stale-snapshot campaign and live-view fix. Extract over the existing Mealie study.

1. Run scripts/Save-Generic-Dependency-Transfer.ps1 -Push to validate the preserved evidence, commit the curated generator and campaign files, and verify the remote commit. This does not run HTTP requests. Existing unselected local files remain outside the commit.
2. Run scripts/Run-Generic-Dependency-Transfer.ps1 -Username changeme@example.com. The runner performs a server/version check, compatibility tests, symbolic generation and sampling, then eight native HTTP schedules against fresh owned resources. Credentials are entered once and restored/cleared after the campaign.
3. Upload the printed campaign.zip. PASS is scoped to the configured invariants. TRANSFER_CANDIDATE is an unconfirmed mismatch; multiple reproductions of one cause are one bug family. No automatic deletion, rollback or reset is performed.

Java heap: 512 MiB. Required free RAM: 1024 MiB; required free disk: 1 GiB. No need to close Chrome if these checks pass.

Food and unit controls execute four target updates without rebinding (125 responses per complete schedule). Transfer cases execute seven phases, including A-to-B transfers for R1 and R2 and a B-to-A return for R1 (152 responses). Each phase checks all three recipe projections and all three targets. Phase ordering is explicit; the two native samples vary the prefix schedule. This pilot does not enumerate all phase permutations.

The archived campaign is the accepted stale-snapshot analysis, not a newly confirmed bug. See evidence/stale-snapshot-20261004/FINDINGS.md. The new transfer campaign has not yet been executed against live Mealie.
